# Turto ir sandėlio valdymo prototipas

Vieno puslapio veikiantis demonstracinis prototipas. Papildomų bibliotekų, serverio ar diegimo komandų nereikia.

## Publikavimas su GitHub Pages

1. GitHub sukurkite naują viešą arba privatų repozitoriją.
2. Į repozitorijos pagrindinį katalogą įkelkite visus šio paketo failus.
3. Atverkite **Settings → Pages**.
4. Dalyje **Build and deployment** pasirinkite **Deploy from a branch**.
5. Pasirinkite šaką **main**, katalogą **/(root)** ir spauskite **Save**.
6. Po kelių minučių GitHub parodys paskelbtą prototipo adresą.

Pagrindinis svetainės failas yra `index.html`. Prototipo pakeitimai naršyklėje saugomi tik tame įrenginyje.
